# LoopLab

## Working agreement

- Read the relevant existing code before proposing any change. Do not
  assume the file layout or the conventions.
- Never write, edit or delete files until I have approved a plan.
- For any task, respond first with: what you found, what you propose,
  which files you would create or modify, and what you are uncertain
  about. Then stop and wait.
- Flag structural decisions separately: new dependency, new build step,
  schema change, hosting change. I decide those.
- I have a few hours a week. Prefer the smaller, duller solution that
  ships. If a task is bigger than the prompt implies, say so rather
  than quietly building a weaker version.
- Reuse what exists. This repo already has a hand-written Web Audio
  synth, MIDI export, genre groove data and Supabase auth. Do not add
  a library or a service that duplicates something already here.
- No new infrastructure beyond Supabase, Render and GitHub Pages.
- Plain British English in all user-facing copy. Keep the dark,
  high-contrast aesthetic.
